# TexFi Hyprland

Форк [end-4/dots-hyprland](https://github.com/end-4/dots-hyprland) (illogical-impulse)
в стиле **TexFi** — фирменный пиксель-арт визуальный язык: акцент `#4a7dfb`,
острые углы без скруглений, Press Start 2P только на крупных заголовках и
цифрах, плоские офсетные тени без blur, пиксельный таймер и pixel-dissolve
у уведомлений вместо гладких Material-переходов.

Вся благодарность и основная работа — оригинальному проекту end-4/dots-hyprland.
Этот форк меняет только визуальный слой: тема, шрифты, скругления, анимации,
несколько виджетов бара и сайдбара, плюс отдельный набор обоев.

## Что изменено

- **Тема**: акцент `#4a7dfb`, палитра `scheme-tonal-spot`, генерация через matugen.
- **Скругления**: `rounding = 0` везде — бар, сайдбар, попапы, окна, кнопки.
- **Анимации**: словарь длительностей/кривых из `custom/general.conf`
  (150–300мс, easeOut/easeIn/easeOutBack) вместо дефолтных Material.
- **Шрифт**: Press Start 2P на заголовках и крупных числах (таймер, часы),
  обычный шрифт — везде, где текст читают часто (списки, подписи).
- **Виджеты бара**: индикаторы CPU/RAM/media — пиксельное сегментированное
  кольцо вместо гладкой Material-дуги; батарея, острова воркспейсов —
  прямоугольные вместо капсул.
- **Поиск/лаунчер**: панель — PixelCard с рамкой вместо Material-капсулы;
  бейджи режимов поиска — один пиксельный кружок вместо органических
  Material-шейпов (Clover/Gem/Sunny/Burst).
- **Уведомления**: pixel-dissolve вместо fade — появление/исчезновение
  блоками пикселей со сканлайнами.
- **Таймер в сайдбаре**: сегментированное пиксельное кольцо (60 сегментов,
  как в TexFi-приложениях) вместо гладкой Material-дуги.
- **Kitty**: блочный курсор вместо beam, без motion-blur трейла, курсор и
  выделение — фирменный синий (фиксированный, не завязан на обои).
- **fastfetch**: лого — пиксельный ASCII-бейдж вместо дефолтного логотипа
  дистрибутива, тем же синим.
- **Обои**: отдельный [набор из 5 композиций](texfi-wallpapers/README.md)
  (cascade / matrix / horizon / halo / wedge) — только тёмные, один акцентный
  штрих, без логотипов и надписей.

## Установка

Сначала поставь базовый illogical-impulse (если ещё не стоит):
<https://end-4.github.io/dots-hyprland/>

Дальше — одна команда, накладывает TexFi поверх:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/mistqkw/texfi-hyprland/texfi-skin/install-texfi.sh)
```

Или вручную:

```bash
git clone --branch texfi-skin https://github.com/mistqkw/texfi-hyprland.git
cd texfi-hyprland
./install-texfi.sh
```

Скрипт бэкапит текущие `~/.config/{hypr,quickshell,kitty,fastfetch}` в
`~/texfi-hypr-backup-<дата>` перед тем как что-то перезаписать.
